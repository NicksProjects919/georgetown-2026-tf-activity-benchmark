# Georgetown Internship Project 2026: Benchmarking Transcription Factor Activity Pipelines

This repository contains the code, configurations, documentation, and summarized results from a comparison of nf-core/tfactivity, TF-Prioritizer, and diffTF using matched ENCODE data from K562 and MCF7 cells.

The project evaluates agreement among the pipelines' transcription factor predictions and compares their runtime, storage requirements, usability, portability, and recovery from interrupted runs.
